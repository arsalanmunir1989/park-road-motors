# Park Road Motors – Website Design Template (HTML)

Open **index.html** in any modern browser (Chrome, Edge, Safari, Firefox). No installation or server is needed.

## Pages

| File | Page |
|---|---|
| index.html | Home: hero slider, Shop Cars search, top-selling / latest arrivals slider, collections, brands, about, showroom |
| cars-for-sale.html | Car listings with working filters (brand, body type, max price) |
| car-details.html | Car details with gallery, 360° view, specs and enquiry form |
| mobile-home.html | Mobile (390 px) version of the home page |
| admin-login.html | Admin sign-in |
| admin-dashboard.html | Admin dashboard: approval queue, homepage slider and top-selling managers |
| admin-listings.html | All listings: approve, reject, feature, edit, delete |
| admin-listing-editor.html | Add / edit a car advert with multi-photo upload |
| admin-catalog.html | Brands, models and body types |

All pages link to each other.

## Folder contents

- `assets/mark.png`, `assets/wordmark.png`: logo files (transparent background)
- `assets/studio.jpg`, `assets/trails.jpg`, `assets/carbon.png`, `assets/pattern.png`: background images
- `assets/prm-runtime.js`: small script that powers the sliders, filters, approve/reject buttons, tabs and animations

## Notes

- Fonts (Montserrat, Saira) load from Google Fonts. Offline, the browser uses a fallback font.
- Car photo areas are placeholders marked "PHOTO". Replace them with real photos when building the live site.
- Car listings, prices and enquiries are sample data. Text in [BRACKETS] (phone, address, about text) is placeholder content.
- This is a front-end design prototype. Real data, admin sign-in and image uploads need a back end (for example ASP.NET Core with a database).
